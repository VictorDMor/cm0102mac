## Preserved behavior

`release_catalog` invokes the original array destructor only for a nonnull catalog,
then clears the live catalog slot and stores the invalid selected-language byte
`0xff`. It retains the 0x40-byte frame, link handling and original temporary values.

`destroy_record` accepts a nullable record and deletion flag in r3/r4. It releases
the three leading string pointers in order, reading each pointer after preceding
children return. Those fields and the ten metadata words remain in memory. Only
the **signed low halfword** of the flag decides whether to deallocate the record
itself. The return value is the original record pointer, including null. The
component confirms that the routine itself does not read a TOC slot; its modeled
children remain a separate service boundary.

`language_availability` rejects the signed selected-language marker -1 through the
original reporting sequence, status-byte store and error-string copy. Otherwise
it scans the live advertised count and compares signed low bytes, returning a
boolean. It does not replace negative counts or unmapped accesses with safe defaults.

`initialize_catalog` preserves its complete 0x1e0-byte frame, r18..r31 spills,
link, architectural flags, original temporary residues, instruction PCs and
instruction accounting. Its named stages retain the following sequence:

- Reject an uninitialized catalog, optionally format the progress label, destroy
  an existing catalog, invalidate the selected language and open the original file.
- Query the stream's original byte-order selector, read version 1 or 2 and restore
  row/language counts with ordered live reads and byte insertion operations.
- Read every language ID. Version 2 omits IDs 0 and 1 from the advertised list;
  a selected translation still uses its physical on-disk column index.
- On an absent selection, record the original message, close the current stream
  and recursively invoke the complete initializer using the first advertised ID.
  An empty advertised list returns false.
- Store the selected language. Only mode byte 1 and a nonzero signed language byte
  enter cached construction. The other successful paths close and refresh without
  allocating catalog records.
- Allocate the original array, construct 52-byte records through its callback ABI,
  read source/descriptor/translation fields, copy ten metadata words and retain
  selected-column skips and unchecked read results.
- Remove source braces in place, then independently remove spaces and decode
  newline escapes into the shared buffer before replacing the owned source string.
  Original live pointer reloads, allocation stores and release ordering remain.
- Report progress at the original reciprocal-multiply interval and final row,
  invoke the original sorting child, close the stream and refresh the service.

The original error paths retain their distinct messages, status effects, cleanup,
stream ownership and return registers. No alternate format, retry policy, bounds
correction, general fallback or replacement sorting algorithm is introduced.
