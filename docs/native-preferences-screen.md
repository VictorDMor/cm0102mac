## Original screen construction

The root captures the current edit record and screen mode from the UI manager.
It caches the original style-cell, text-buffer, string-bank and UI-context
pointers. The lazy color flag controls the first color lookup; that lookup's
low halfword is stored before the flag becomes one. Later display calls retain
their own live style-value reads and original pointer-caching behavior.

Available languages are counted through eleven validator calls. Zero or one
available language selects a shorter panel and omits the language selector.
When the selector exists, availability is queried again while enumerating
the eleven original language names. A later change in availability therefore
does not retroactively change the initial panel dimensions. The current
language's display label and each selectable/disabled row retain their original
ordering. A present language panel can reject nonzero language choices through
the separate language-binding query.

The currency selector obtains all 25 names through the complete existing
currency-label operation. The current choice receives its separate display
label. The video section reads the complete stored mode through the existing
getter and requests its description. Its additional device enumeration uses
at most twenty entries, skips nonpositive counts and retains the two original
special-mode choices. These are presentation decisions, not new device policies.

The screen's low mode byte affects the outer panel, row construction and
whether controls are editable. In mode 3 the current values can still be drawn,
while editable language, currency, video and auto-save choices are omitted.
Database and stored-match choices also retain their mode-2/mode-3 restrictions.

## Option groups and action payloads

The option grid builds wages, screen mode, background changes, sound, database
size, retained-match count, auto-save, compression, safe saving, flashing text,
background-match behavior and print destination. It retains the original
selected/unselected styles, masks, control types, row offsets, text arguments
and event payloads. Invalid combinations of stored option bits keep the
original presentation; the builder does not normalize them.

Language choices carry action 42 with the language index; currency choices
carry action 43 with indices 0..24; video choices carry action 61. The original
six editable auto-save choices carry action 45 with values **7, 14, 30, 90, 180
and 360**. The separate Never choice carries action 44 and option `0x1000`.
The action controller, rather than this builder, changes the preference record.
The calendar scheduler remains separate, unreconstructed work.

Shared row helpers retain distinct source locations and argument sequences.
There is no runtime interpretation or dispatch of this root's original body,
no copied original instruction bank and no new owner for an interior stage.
The public `build_screen` method owns the whole original frame and epilogue.
